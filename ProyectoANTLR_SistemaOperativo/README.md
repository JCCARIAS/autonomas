# Proyecto ANTLR - Sistema Operativo

## Instrucciones
1. Abre este proyecto en IntelliJ IDEA o VS Code.
2. Asegúrate de tener **Java 21** y **Maven** instalados.
3. En la terminal, ejecuta:
   ```bash
   mvn clean package
   ```
4. Para correr el programa:
   ```bash
   mvn exec:java -Dexec.mainClass="com.example.pseudocode.Main" -Dexec.args="sample_input.txt"
   ```

El reporte de validación se mostrará en consola.
